# 项目模块开发清单

> 基于项目模块设计说明，按开发阶段列出的任务清单。表结构见 `scripts/sql/V2__project_module.sql`。

---

## 一、表结构一览

| 表名 | 说明 |
|------|------|
| project | 项目主表 |
| project_participant | 项目参与者（project_id + user_id + role 绑定） |
| generated_content | 生成物（与项目绑定，交付物模块负责 CRUD） |

---

## 二、开发任务清单

### 阶段一：基础设施

| 序号 | 任务 | 说明 | 产出 |
|------|------|------|------|
| 1.1 | 数据库脚本执行 | 执行 V2__project_module.sql | 表已创建 |
| 1.2 | 实体类 | Project, ProjectParticipant, GeneratedContent | Entity |
| 1.3 | 枚举类 | ProjectStatus, ParticipantRole, ParticipantStatus, ContentType | Enum |
| 1.4 | Repository | ProjectRepository, ProjectParticipantRepository, GeneratedContentRepository | Repository |

### 阶段二：项目生命周期

| 序号 | 任务 | 说明 | 产出 |
|------|------|------|------|
| 2.1 | 创建项目 | 填写新郎/新娘姓名、婚礼日期；扣配额；生成 share_token | POST /api/b/projects |
| 2.2 | 项目列表 | 主持人自己的项目，分页、排序 | GET /api/b/projects |
| 2.3 | 项目详情 | 含素材库概览、生成物列表、成员状态 | GET /api/b/projects/{id} |
| 2.4 | 项目归档 | 可选，v0.1 可简化 | PUT /api/b/projects/{id}/archive |

---

### 阶段三：分享

| 序号 | 任务 | 说明 | 产出 |
|------|------|------|------|
| 3.1 | 分享入口 | 根据 share_token 生成二维码、链接 | GET /api/b/projects/{id}/share |
| 3.2 | 扫码解析 | C 端通过 token 解析 project_id，进入身份选择页 | GET /api/c/entry/{token} |

---

### 阶段四：成员绑定（C 端进入流程）

| 序号 | 任务 | 说明 | 产出 |
|------|------|------|------|
| 4.1 | 用户存在性判断 | 根据微信 openid 查询用户，不存在则创建 | 用户模块提供 / 项目模块调用 |
| 4.2 | 身份选择页 | 展示 project 信息，新郎/新娘二选一，授权勾选 | C 端页面 + GET /api/c/projects/{token}/info |
| 4.3 | 绑定接口 | 选择身份后，创建 project_participant（project_id + user_id + role） | POST /api/c/projects/{id}/bind |
| 4.4 | 席位校验 | 同一项目下同一角色只能绑定一人 | Service 层校验 |

---

### 阶段五：项目成员与生成物展示

| 序号 | 任务 | 说明 | 产出 |
|------|------|------|------|

| 5.2 | 生成物列表 | 按 project_id 查询，展示开场白/新郎誓言/新娘誓言状态 | 项目详情接口 / 交付物模块提供 |

---

### 阶段六：与其它模块对接

| 序号 | 任务 | 说明 | 产出 |
|------|------|------|------|
| 6.1 | 创建项目扣配额 | 调用 UserQuotaService.checkQuota + deduct | 项目创建时 |

## 三、接口汇总

### B 端（主持人）

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/b/projects | 创建项目 |
| GET | /api/b/projects | 项目列表 |
| GET | /api/b/projects/{id} | 项目详情 |
| GET | /api/b/projects/{id}/share | 分享入口（二维码、链接） |

### C 端（扫码进入）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/c/entry/{token} | 根据 token 获取项目信息，进入身份选择 |
| GET | /api/c/projects/{token}/info | 身份选择页所需项目信息 |
| POST | /api/c/projects/{id}/bind | 选择身份后绑定（需先完成微信登录/用户创建） |

## 四、核心流程说明

### 4.1 创建项目

```
主持人填写 → 校验配额 → 扣配额 → 创建 project → 生成 share_token → 返回
```

### 4.2 扫码进入与绑定

```
扫码(带 token) → 解析 project_id
→ 微信授权/静默登录 → 用户模块：判断用户是否存在，不存在则创建 → 得到 user_id
→ 展示身份选择页（新郎/新娘）
→ 用户选择身份 + 勾选授权
→ POST /bind：创建 project_participant(project_id, user_id, role)
→ 进入采访（会话管理）
```

### 4.3 项目详情

```
项目基本信息 + 成员列表(含绑定状态、进度) + 生成物列表(按 project_id)
```
