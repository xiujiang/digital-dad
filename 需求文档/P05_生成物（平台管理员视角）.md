# P05_生成物（平台管理员视角）


## 0）页面定位

- **端**：统一后台（平台管理员账号）

- **页面编号**：P05_生成物（平台管理员视角）

- **页面目的**：平台管理员集中查看全平台“已生成/生成中/失败/待更新”的交付内容，用于排查问题、支持主持人、回溯生成历史。

- **入口**：左侧菜单「生成物」

- **出口**：

- 点击某条生成物进入「生成物详情」

- 需要回到项目时：跳转到「项目管理 → 项目详情」


重要边界（必须写进本页）：
平台管理员在本页看到的所有生成物均为“主持人交付稿/项目交付内容”。**本页任何操作不得反向改写 C 端用户的数字资产**；若 C 端内容变更，只能触发“已更新提醒/待重生成”状态。


## 1）页面结构与展示

### 1.1 顶部标题区

- 标题：生成物

- 副说明（可选）：查看全平台交付稿生成情况，支持排查与补生成

### 1.2 筛选区（平台管理员必备）

筛选项建议一行展示（可折叠）：

- **项目筛选**：全部项目 / 选择某个项目

- **主持人筛选**：全部 / 选择某主持人

- **生成物类型**：全部 / 开场白 / 新郎誓言 / 新娘誓言 / 新郎父亲致辞 / 新郎母亲致辞 / 新娘父亲致辞 / 新娘母亲致辞（首期固定这 7+1 类）

- **状态筛选**：全部 / 已生成 / 生成中 / 失败 / 待更新

- **时间范围**：最近 7 天 / 30 天 / 自定义


说明：平台管理员需要跨项目查异常，所以必须支持“全部项目”视角；同时也要能落到单项目排查。

### 1.3 列表区（生成物清单）

列表以“表格或卡片”形式均可，但必须包含以下可见信息：

- 生成物名称（如：婚礼开场白 / 新郎誓言）

- 所属项目（新人名对 + 婚礼项目名）

- 所属主持人（姓名）

- 最近生成时间

- 状态标签：

- **已生成**（可查看/下载）

- **生成中**（显示进度提示）

- **失败**（显示失败提示与重试入口）

- **待更新**（显示“素材已更新”提示）

- 操作入口（每条至少 2 个）：

- 查看详情

- 更多操作（三点）


## 2）状态定义（平台管理员能看懂的口径）

### 2.1 已生成

- 表示：该类型生成物当前存在“可交付版本”

- 行为：允许查看、复制、下载

### 2.2 生成中

- 表示：正在生成或正在排队

- 行为：可查看“生成进度提示”，可取消（可选，首期不强制）

### 2.3 失败

- 表示：生成未成功产出交付稿

- 必须展示：失败原因简述（一句话即可）

- 行为：提供“重试生成”

### 2.4 待更新（关键）

- 表示：该项目对应的采访沉淀（C 端那 4 份内容）发生了变更，导致当前生成物版本可能过期

- 必须展示：提示语“素材已更新，建议重新生成”

- 行为：提供“一键重生成”（见 4.3）


这里与「项目详情页 → 素材库更新提示弹窗」口径一致：
**C 端变更可以影响 B 端显示“已更新/待更新”；B 端任何操作不能回写 C 端。**


## 3）三点菜单（更多操作）

点击列表右侧三点，弹出菜单（最小可用）：

1. **查看详情**

- 等价于点整条进入详情页

1. **重试生成 / 重新生成**（根据状态自动命名）

- 失败时显示“重试生成”

- 待更新时显示“重新生成”

1. **下载**

- 下载当前生成物为文档（格式由实现决定）

- 或提供“复制全文”


## 4）生成物详情页（点击“查看详情”进入）

### 4.1 基本展示区

- 顶部展示：

- 生成物名称（如：新郎誓言）

- 所属项目（新人名对）

- 主持人信息

- 状态标签（已生成/失败/待更新）

- 正文区域：

- 以可阅读的排版展示全文

- 支持复制全文

### 4.2 版本与历史（平台排查必须）

- 展示“最近一次生成版本”的时间

- 提供“查看历史版本”入口（可做折叠列表）：

- 每条显示：生成时间 + 状态（成功/失败）

- 点击可切换预览该版本内容（若成功）


说明：这里的“版本”只针对“生成物交付稿”。
不等同于 C 端的文章资产版本；禁止在这里出现“编辑并保存到 C 端”的入口。

### 4.3 重新生成行为（核心规则）

当平台管理员在详情页点“重新生成/重试生成”：

- 若状态为失败：直接发起重试

- 若状态为待更新：弹出确认框

确认框文案建议：

- 标题：确认重新生成？

- 说明：将基于最新采访沉淀重新生成该交付稿，用于主持人交付。不会影响任何参与者的个人资产内容。

- 按钮：取消 / 确认生成

生成后结果：

- 成功：状态变为“已生成”，并生成新的历史记录

- 失败：状态为“失败”，保留失败原因简述


## 5）与配额/扣费口径的关系（本页只展示一句话）

- 本项目配额扣减口径：**仅创建项目成功才扣 1 次**

- 因此本页的“生成/重试/重生成”不会触发扣次变化

- 但平台侧需要可追溯：相关记录统一进入「生成日志/审计记录」（不在本页展开）


## 6）异常与空态

### 6.1 空态

- 筛选后无结果：提示“暂无生成物记录”

- 可附引导：去项目管理查看某个项目的生成物情况

### 6.2 网络/系统异常

- 提示“加载失败，请重试”

- 重试按钮：刷新列表

### 6.3 生成中断/失败

- 列表与详情都要展示“失败”状态与“重试生成”入口


## 7）验收口径（可测试）

1. 进入 P05，默认展示“全部项目”的生成物列表，并支持按项目/主持人/类型/状态筛选。

1. 列表每条均展示：生成物名称、所属项目、主持人、最近生成时间、状态、操作入口。

1. 状态为“待更新”的条目明确提示“素材已更新，建议重新生成”。

1. 点击三点菜单至少包含：查看详情、重试/重新生成、下载/复制。

1. 进入详情页可查看全文；可查看历史版本列表；点击重试/重新生成后能生成新记录或显示失败原因。

1. 本页任何操作不出现“回写参与者资产”的入口与文案，且在确认框中明确“不影响参与者个人资产”。
