# 用户模块开发清单

> 基于用户模块表结构，按开发阶段列出的任务清单。表结构见 `scripts/sql/V1__user_module.sql`。

---

## 一、表结构一览

| 表名 | 说明 |
|------|------|
| user | 用户主表（超管/主持人/C端微信用户） |
| user_wechat | 微信用户扩展 |
| user_admin | 超管扩展（账号密码） |
| user_member | 会员信息 |
| user_quota | 配额 |
| quota_flow | 配额流水 |
| sms_code | 验证码记录（可选） |

---

## 二、开发任务清单

### 阶段一：基础设施

| 序号 | 任务 | 说明 | 产出 |
|------|------|------|------|
| 1.1 | 数据库脚本执行 | 执行 V1__user_module.sql，创建表 | 表已创建 |
| 1.2 | 实体类 (Entity) | 对应 7 张表的 JPA 实体 | User, UserWechat, UserAdmin, UserMember, UserQuota, QuotaFlow, SmsCode |
| 1.3 | 枚举类 | 用户类型、状态、流水类型等 | UserType, UserStatus, FlowType, QuotaType 等 |
| 1.4 | Repository 接口 | JPA Repository | UserRepository, UserWechatRepository 等 |
| 1.5 | 基础配置 | Redis、JWT、短信等配置类 | application.yml 扩展、JwtProperties 等 |

---

### 阶段二：登录与认证

| 序号 | 任务 | 说明 | 产出 |
|------|------|------|------|
| 2.1 | 发送验证码 | 手机号校验、限流(Redis 60s)、调用短信服务、存储验证码(Redis 5min) | POST /api/auth/send-code |
| 2.2 | 主持人登录 | 校验验证码、账号状态、签发 JWT | POST /api/auth/login |
| 2.3 | 超管登录 | 账号密码 或 手机号+验证码，签发 JWT | POST /api/admin/auth/login |
| 2.4 | 微信登录 | 接收 code/openid，创建/绑定用户，签发 JWT | POST /api/c/auth/wechat-login |
| 2.5 | 退出登录 | 清除 Token（黑名单或客户端清除） | POST /api/auth/logout |
| 2.6 | Token 校验 | 鉴权过滤器/拦截器，解析 JWT 获取 userId、userType | Filter/Interceptor |
| 2.7 | 当前用户信息 | 根据 Token 返回用户基本信息 | GET /api/auth/me |

---

### 阶段三：主持人 - 我的资料

| 序号 | 任务 | 说明 | 产出 |
|------|------|------|------|
| 3.1 | 我的资料-查询 | 返回姓名、电话、会员状态、配额、有效期、联系方式展示 | GET /api/b/users/me |
| 3.2 | 我的资料-更新 | 更新姓名、电话、contact_visible | PUT /api/b/users/me |
| 3.3 | 会员信息组装 | 从 user_member、user_quota 组装启用状态、剩余场次 | Service 层 |

---

### 阶段四：配额与流水

| 序号 | 任务 | 说明 | 产出 |
|------|------|------|------|
| 4.1 | 配额查询 | 按 user_id、quota_type 查询剩余配额 | UserQuotaService.getRemaining() |
| 4.2 | 配额扣减 | 创建项目时扣减，写 quota_flow，事务保证 | UserQuotaService.deduct() |
| 4.3 | 配额调整 | 超管增减配额，写 quota_flow | UserQuotaService.adjust() |
| 4.4 | 配额流水查询 | 分页查询某用户的流水记录 | GET /api/admin/hosts/{id}/quota-flows |
| 4.5 | 配额预校验 | 创建项目前校验剩余配额是否充足 | 供项目管理模块调用 |

---

### 阶段五：主持人管理（超管端）

| 序号 | 任务 | 说明 | 产出 |
|------|------|------|------|
| 5.1 | 主持人列表 | 分页、按状态/套餐/配额筛选、搜索姓名/手机号 | GET /api/admin/hosts |
| 5.2 | 新增主持人 | 手机号、姓名、初始配额，创建 user+user_quota | POST /api/admin/hosts |
| 5.3 | 主持人详情 | 基本信息、会员、配额、最近登录、备注 | GET /api/admin/hosts/{id} |
| 5.4 | 启用/停用 | 更新 user.status | PUT /api/admin/hosts/{id}/status |
| 5.5 | 调整配额 | 增减配额，填写原因，写 quota_flow | PUT /api/admin/hosts/{id}/quota |

---

### 阶段六：微信用户

| 序号 | 任务 | 说明 | 产出 |
|------|------|------|------|
| 6.1 | 微信 code 换 openid | 调用微信 API 获取 openid/unionid/session_key | WechatAuthService |
| 6.2 | 微信用户创建/绑定 | 首次进入创建 user+user_wechat，再次进入更新信息 | UserWechatService.bindOrCreate() |
| 6.3 | 微信用户信息更新 | 授权后更新昵称、头像等 | PUT /api/c/users/me（可选） |

---

### 阶段七：超管管理（可选，v0.1 可简化）

| 序号 | 任务 | 说明 | 产出 |
|------|------|------|------|
| 7.1 | 超管初始化 | 启动时或脚本初始化 1 个超管账号 | 初始化脚本或配置 |
| 7.2 | 超管密码修改 | 修改登录密码 | PUT /api/admin/users/me/password |

---

### 阶段八：外部集成

| 序号 | 任务 | 说明 | 产出 |
|------|------|------|------|
| 8.1 | 短信服务 | 阿里云/腾讯云短信 API 封装 | SmsService.sendCode() |
| 8.2 | 微信 API | 小程序/H5 微信登录 API 封装 | WechatApiService |
| 8.3 | JWT 工具 | 签发、解析、过期配置 | JwtUtils |

---

### 阶段九：安全与异常

| 序号 | 任务 | 说明 | 产出 |
|------|------|------|------|
| 9.1 | 登录限流 | 同一手机号 60 秒内只能获取 1 次验证码 | Redis 实现 |
| 9.2 | 验证码错误次数 | 同一手机号连续错误 N 次临时锁定（可选） | Redis 实现 |
| 9.3 | 登录失败提示 | 验证码错误/过期、未开通、已禁用、系统异常 | 统一异常处理 |
| 9.4 | 数据权限 | 主持人只能访问自己的数据，超管可访问全平台 | 注解或 Service 层校验 |

## 三、接口汇总

### B 端（主持人）

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/auth/send-code | 发送验证码 |
| POST | /api/auth/login | 登录 |
| POST | /api/auth/logout | 退出 |
| GET | /api/auth/me | 当前用户 |
| GET | /api/b/users/me | 我的资料（含会员、配额） |
| PUT | /api/b/users/me | 更新我的资料 |

### C 端（微信用户）

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/c/auth/wechat-login | 微信登录 |
| GET | /api/c/users/me | 我的信息（可选） |

### 平台管理端（超管）

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/admin/auth/login | 超管登录 |
| GET | /api/admin/hosts | 主持人列表 |
| POST | /api/admin/hosts | 新增主持人 |
| GET | /api/admin/hosts/{id} | 主持人详情 |
| PUT | /api/admin/hosts/{id}/status | 启用/停用 |
| PUT | /api/admin/hosts/{id}/quota | 调整配额 |
| GET | /api/admin/hosts/{id}/quota-flows | 配额流水 |

## 四、v0.1 优先级建议

| 优先级 | 任务 | 说明 |
|--------|------|------|
| P0 | 阶段一、二、三、四、八(短信+JWT)、九 | 主持人登录、我的资料、配额 |
| P0 | 阶段五 | 主持人管理（超管端） |
| P1 | 阶段六 | 微信用户登录与绑定 |
| P2 | 阶段七 | 超管管理 |
| P2 | sms_code 表落库 | 若需审计可启用 |

## 五、与其他模块的对接点

| 调用方 | 调用场景 | 用户模块提供 |
|--------|----------|--------------|
| 项目管理 | 创建项目前 | 校验配额、扣减配额 |
| 各模块 | 请求鉴权 | Token 校验、返回 userId、userType |
| 会话管理 | C 端进入 | 微信用户 identity（user_id） |
