## 1）B端页面清单（主持人管理后台）

### B-P01｜P01_登陆页（主持人后台）

- 入口：后台访问默认页

- 功能：手机号 + 短信验证码登录

- 出口：登录成功 → **P02_项目管理**


### B-P02｜P02_项目管理（列表页）

- 入口：登录成功进入

- 功能：

1. 查看项目卡片列表（含分页）

1. 新建项目入口

1. 进入项目详情

1. 分享采访入口

- 出口：

- 点击“+新建婚礼项目” → **P02_项目管理_新建项目**

- 点击“查看详情” → **P02_项目管理_查看详情**

- 点击“分享采访” → **P02_项目管理_分享采访链接**

- 退出登录 → **P01_登陆页**


### B-P02A｜P02_项目管理_新建项目（弹窗/页）

- 入口：P02_项目管理 → “+新建”

- 功能：

- 填写新郎姓名、新娘姓名、婚礼日期（最小必填集）

- 创建成功后扣配额 1 次

- 出口：

- 创建成功 → 回到 **P02_项目管理**（新项目出现在列表顶部）

- 取消 → 回到 **P02_项目管理**


### B-P02B｜P02_项目管理_分享采访链接（分享页）

- 入口：

- P02_项目管理 项目卡片“分享采访”

- 或 P02_项目管理_查看详情 右上“分享采访入口”

- 功能：

- 展示二维码 + 入口链接（复制/下载/打开）

- 展示“亲友席位上限”等提示（v0.1 实际只做新郎/新娘，但可保留提示位不启用）

- 展示主持人联系方式（受“联系方式展示开关”影响）

- 出口：返回项目列表（浏览器返回/左上返回）


v0.1 关键：分享入口必须能让新郎/新娘进入身份选择页并开始采访。


### B-P02C｜P02_项目管理_查看详情（项目详情页）

- 入口：P02_项目管理 → “查看详情”

- 页面结构（v0.1最小集）：

1. **素材库（只两人）**

- 新郎素材：4个板块的状态/内容摘要

- 新娘素材：4个板块的状态/内容摘要

1. **生成区（只三件套）**

- 开场白（吃新郎+新娘已确认素材包）

- 新郎誓言（只吃新郎已确认素材包）

- 新娘誓言（只吃新娘已确认素材包）

- 出口：

- 右上“分享采访入口” → **P02_项目管理_分享采访链接**

- 返回 → **P02_项目管理**

- 点击生成项“AI生成/查看/编辑” → 留在本页（弹层或右侧抽屉均可，由实现决定）


### （可选）B-P03｜P03_生成日志

- v0.1 可不做；若做仅用于排障与对账（非主链路）

- 不影响 v0.1 闭环


## 2）C端页面清单（参与者端）


说明：你现在叫它 P05_扫码后采访页面（选择身份页），我在 v0.1 沿用该编号。

### C-P05｜P05_扫码后采访页面（选择身份页）

- 入口：B端分享二维码/链接扫码进入

- v0.1 页面规则（写死）：

- 身份只保留 2 个：**新郎 / 新娘**

- 授权勾选必须勾选才可开始

- 出口：

- 点击“开始采访” → **C-Interview｜采访对话页（v0.1新页面，可自定编号）**


注意：原来P05里有父母/亲友入口，v0.1先隐藏或置灰，不开放。


### C-Interview｜采访对话页（v0.1核心页）

- 入口：P05 → 开始采访

- 功能：4板块串行多轮采访（语音优先，支持文字）

- 关键规则：

- 当前板块进行中时：允许继续对话补充

- 板块结束时：必须进入该板块小结确认（下一页/弹层）

- 出口：

- 进入板块小结确认 → **C-Summary｜板块小结页/卡片（v0.1核心）**

- 四板块全部确认完成 → 提示“采访完成”（可停留或返回）


### C-Summary｜板块小结页/卡片（v0.1核心）

- 入口：采访对话页在每板块结束时触发（共4次）

- 展示内容（最小）：

- 标题：{板块名}小结

- 核心要点（<=8条，可编辑/删除/新增）

- 确认按钮

- 规则（写死）：

- 默认未确认

- 用户点击确认后，该板块素材包变为已确认

- 确认后回到采访对话页进入下一板块

- 出口：

- 确认 → 返回采访对话页继续下一板块

- 取消 → 返回采访对话页继续补充（不确认不推进）


## 3）页面跳转关系图（文字版）

### B端主链路

P01_登陆页

→ P02_项目管理

→（新建）P02_项目管理_新建项目 → 回 P02_项目管理

→（分享）P02_项目管理_分享采访链接

→（详情）P02_项目管理_查看详情（素材库/生成区）

### C端主链路

P02_项目管理_分享采访链接（扫码入口）

→ P05_扫码后采访页面（新郎/新娘二选一 + 授权）

→ 采访对话页（板块1）

→ 板块1小结确认

→ 采访对话页（板块2）

→ 板块2小结确认

→ 采访对话页（板块3）

→ 板块3小结确认

→ 采访对话页（板块4）

→ 板块4小结确认

→ 采访完成

### 双端同步节点（关键）

- 每个板块小结“确认成功”后：

- C端生成该板块“已确认素材包”

- B端项目详情页素材库中对应板块状态更新为“已完成/已确认”

- B端生成三件套时：

- 只读取“已确认素材包”

- 禁止读取原始对话原文作为事实来源


## 4）给开发拆任务的最小清单（按页面）

- B端：登录/项目列表（分页）/新建项目/分享页/项目详情（素材库+生成区）

- C端：身份选择页（仅新郎新娘）/采访对话页/板块小结页（4次）

- 同步：板块确认后B端可见；B端生成读取确认素材
