# 数字爸爸 v0.1 业务模块说明

> 本文档描述数字爸爸 v0.1 系统的业务模块划分及各模块职责，供开发与产品参考。

---

## 一、模块总览

数字爸爸 v0.1 按业务域划分为 **7 个核心模块**：

| 序号 | 模块名称 | 核心职责 |
|------|----------|----------|
| 1 | 用户模块 | 用户管理、登录、会员与配额 |
| 2 | 提示词模块 | 提示词配置与供给 |
| 3 | 项目管理 | 项目生命周期、成员、生成物归属、分享 |
| 4 | 板块管理 | 板块配置与实例管理 |
| 5 | 会话管理 | 会话、对话消息、素材（板块小结/故事） |
| 6 | 交付物模块 | 交付物的创建、管理、删除 |
| 7 | 通知模块 | 站内通知 |

---

## 二、各模块说明

### 1. 用户模块 (User Module)

**模块作用**：统一管理系统中所有与「人」相关的身份、认证与权益信息。

**主要职责**：

| 子域 | 说明 |
|------|------|
| 用户管理 | 管理员、主持人、用户等各类角色的信息维护，包括基础资料、状态、角色归属 |
| 登录相关 | 手机号+验证码登录、Token 签发与校验、Session 管理 |
| 会员与配额 | 会员状态、项目配额、生成配额等权益管理，创建项目时扣减配额 |

**服务对象**：B 端主持人、平台管理员、C 端参与者（若纳入用户体系）

**依赖关系**：为其他模块提供身份与权限校验、配额校验能力。

---

### 2. 提示词模块 (Prompt Module)

**模块作用**：集中管理各业务场景所需的提示词配置，并向其他模块提供提示词内容。

**主要职责**：

| 子域 | 说明 |
|------|------|
| 提示词管理 | 维护各维度的提示词，包括：4 个采访板块的提问提示词、板块小结提示词、交付物生成提示词等 |
| 提示词供给 | 根据业务场景（采访、小结、生成）返回对应的提示词内容，支持版本管理 |

**服务对象**：会话管理（采访与小结）、交付物模块（生成）

**依赖关系**：被会话管理、交付物模块调用，作为基础能力模块，不依赖其他业务模块。

---

### 3. 项目管理 (Project Module)

**模块作用**：以「项目」为核心，管理婚礼项目的全生命周期及项目下的成员与生成物归属。

**主要职责**：

| 子域 | 说明 |
|------|------|
| 项目生命周期 | 项目的创建、归档、状态流转（草稿/进行中/已完成/已归档等） |
| 项目用户信息 | 项目中各类用户信息管理，如新郎、新娘等采访对象的身份、状态、进度 |
| 项目生成物管理 | 从项目视角管理归属该项目的交付物，包括列表、状态、是否有更新等 |
| 分享 | 生成并管理项目的采访入口（二维码、链接），支持复制、下载、打开 |

**服务对象**：B 端主持人、平台管理员

**依赖关系**：依赖用户模块（主持人身份、配额扣减）；为会话管理、交付物模块提供项目上下文。

---

### 4. 板块管理 (Board Module)

**模块作用**：管理采访流程中的「板块」配置与实例，支撑 4 板块串行采访机制。

**主要职责**：

| 子域 | 说明 |
|------|------|
| 板块配置 | 板块类型定义（原生家庭、成长轨迹、爱情故事、未来承诺）、顺序、与提示词的关联 |
| 板块实例 | 每个参与者下的板块实例管理，包括状态、进度、是否已确认等（v0.1 板块类型写死，可做薄） |

**服务对象**：会话管理、项目管理

**依赖关系**：依赖提示词模块（板块与提示词关联）；为会话管理提供板块结构与状态。

---

### 5. 会话管理 (Session Module)

**模块作用**：管理用户与 AI 的对话全流程，包括会话、消息及由此产生的素材（板块小结、故事）。

**主要职责**：

| 子域 | 说明 |
|------|------|
| 会话管理 | 采访会话的创建、恢复、中断、超时处理，同一参与者同一时刻仅允许一个活跃会话 |
| 对话消息 | 用户与 AI 的对话消息存储，支持文本与语音（含转写），维护消息顺序与归属 |
| 素材管理 | 板块小结的生成、展示、编辑、确认；确认后形成素材快照，作为交付物生成的唯一依据 |

**核心流程**：会话 → 多轮对话 → 板块结束触发小结 → 用户编辑并确认 → 素材快照冻结

**服务对象**：C 端参与者、B 端主持人（只读查看）

**依赖关系**：依赖项目管理（项目与参与者）、板块管理（板块结构）、提示词模块（采访与小结提示词）；为交付物模块提供已确认素材。

---

### 6. 交付物模块 (Deliverable Module)

**模块作用**：管理婚礼场景下的最终交付内容，包括开场白、新郎誓言、新娘誓言等，负责创建、生成、编辑与删除。

**主要职责**：

| 子域 | 说明 |
|------|------|
| 交付物管理 | 交付物的查询、编辑、版本管理、状态标记（如素材更新后的过期标记） |
| 创建与删除 | 发起生成任务（基于已确认素材）、保存编辑结果、删除交付物 |

**交付物类型（v0.1）**：
- 婚礼开场白：综合新郎 + 新娘的已确认素材
- 新郎誓言：仅新郎的已确认素材
- 新娘誓言：仅新娘的已确认素材

**硬规则**：生成必须基于会话管理提供的已确认素材快照，禁止直接使用原始对话原文。

**服务对象**：B 端主持人

**依赖关系**：依赖项目管理（项目归属）、会话管理（素材快照）、提示词模块（生成提示词）；生成完成时可触发通知模块。

---

### 7. 通知模块 (Notification Module)

**模块作用**：统一处理站内通知的触发与推送。

**主要职责**：

| 子域 | 说明 |
|------|------|
| 站内通知 | 根据业务事件（如素材更新、生成完成等）触发站内通知，支持消息列表、未读状态等 |

**说明**：短信验证码等能力归属用户模块的登录流程，本模块专注站内通知。

**服务对象**：B 端主持人、C 端参与者

**依赖关系**：被用户模块、项目管理、会话管理、交付物模块等调用，作为被动触发的能力模块。

## 四、模块与端对应关系

| 模块 | B 端（主持人） | C 端（参与者） | 平台管理端 |
|------|----------------|----------------|------------|
| 用户模块 | 登录、配额查看 | - | 用户管理、主持人管理 |
| 提示词模块 | - | - | 提示词配置 |
| 项目管理 | 项目列表、新建、详情、分享 | - | 项目管理 |
| 板块管理 | - | - | 板块配置（可选） |
| 会话管理 | 查看采访进度、素材 | 采访对话、板块小结 | 会话日志 |
| 交付物模块 | 生成、编辑、查看 | - | 生成物管理 |
| 通知模块 | 站内消息 | 站内消息 | - |
