# P03_生成日志｜主持人后台生成记录与配额流水


### 1）页面定位

- **端**：B 端（主持人管理后台）

- **页面目的**：让主持人清晰看到**自己账号名下**所有 AI 内容生成的历史记录、成功/失败状态、以及与“配额/扣费”相关的关键流水，用于交付追溯与自查异常。


### 2）页面范围与口径对齐

#### 2.1 “全部项目”是什么意思

- **全部项目**＝当前登录的主持人账号名下的**全部婚礼项目**的生成日志汇总

#### 2.2 “按项目筛选”是什么意思

- 仅展示所选项目（某一场婚礼）下发生的生成记录与配额流水

- 用于单项目交付排查与对话回溯


### 3）信息结构（页面组成）

#### 3.1 页面标题区

- 标题：生成日志

- 说明：查看内容生成历史记录与状态

#### 3.2 筛选区（必须）

- 筛选维度 1：**项目筛选**

- 选项：`全部项目（本账号）` / `按项目切换（下拉选择某项目）`

- 默认：

- 从左侧菜单进入：默认 `全部项目（本账号）`

- 从项目详情页进入：默认定位到 `当前项目`

- 筛选维度 2：**状态筛选**

- 选项：全部 / 成功 / 失败

- 筛选维度 3：**时间范围**

- 选项：最近7天 / 最近30天 / 自定义


### 4）日志列表展示（核心）

列表为表格展示，按时间倒序排列（最新在最上）。

#### 4.1 列字段（建议固定）

1. **时间**（必填）

1. **项目**（在“全部项目”视角必显示；在“按项目筛选”可隐藏或弱化）

1. **内容类型**（必填）

1. **来源通道/角色**（必填）

- 示例：新郎 / 新娘 / 男方父亲 / 女方母亲 / 男方其他亲友-大伟 / 女方其他亲友-王阿姨

- 说明：父母致辞只吃对应父母自己的素材通道；其他亲友来自“其他亲友通道”的某个具体人

1. **状态**（必填）

- 成功（绿色）

- 失败（红色）

1. **配置版本**（可选显示）

- 用于主持人判断：同样素材为什么前后输出不同（仅显示版本号，不展开技术细节）

1. **配额变化**（必填）

- 展示：`扣 1` / `不扣` / `+60` 等

- 说明：主持人一眼看懂“是否扣配额、扣多少、何时充值加了多少”


### 5）日志需要覆盖的事件类型（你要求的“都要有哪些”）

生成日志不是只记录“AI生成”，还要记录与配额强相关的关键事件。建议分 3 大类：

#### A. 生成类（内容产出相关）

- 婚礼致辞：

- 主持人开场白（生成/重新生成）

- 新郎誓言（生成/重新生成）

- 新娘誓言（生成/重新生成）

- 新郎父亲致辞（生成/重新生成）

- 新郎母亲致辞（生成/重新生成）

- 新娘父亲致辞（生成/重新生成）

- 新娘母亲致辞（生成/重新生成）

- 给孩子的一封信（生成/重新生成）

- 给父母的一封信（生成/重新生成）

- 亲友片集（生成/重新生成）

- （如有）导出动作也可记一条“导出类日志”（见 C 类）


说明：截图仅供参考，**父母四个致辞位置必须存在并记录日志**。

#### B. 配额类（扣费/配额变动必须入账）

- 创建项目成功（扣配额）

- 购买/开通会员导致配额增加（例：+50 场 / +60 场）

- 续费导致配额增加（再次 +XX）

- 配额调整（如未来存在人工补偿/赠送，也必须可追溯）

#### C. 交付类（建议记录，便于主持人自证交付）

- 导出（导出 Word/PDF 等）

- 采用新版本（当“素材更新/版本对比”发生采纳行为时，记一条：某通道 v1.0 → 采纳 v2.0）


### 6）扣配额规则（必须写死口径）

你已明确的最终口径：

1. **只有“创建项目成功”才扣配额**

- 创建项目失败：不扣

- 生成成功/失败：均不扣（只记日志）

1. **生成失败不扣配额**

- 日志里照样显示失败，并在“配额变化”列写：不扣

1. **配额增加必须记日志**

- 会员开通/续费后：必须产生一条“配额 +XX”的记录

- 这条记录用于主持人自己对账


### 7）状态与失败提示（面向主持人的文案口径）

- 状态=成功：说明本次生成已完成，可在项目内查看/导出

- 状态=失败：提示应尽量可操作、非技术化，例如：

- “素材不足：该通道尚未完成采访或内容过少，建议先补充采访后再生成”

- “系统繁忙：请稍后重试”

- “网络异常：请检查网络后重试”


### 8）权限与数据边界（与 C 端资产不冲突）

- 本页展示的是主持人侧可见的交付数据与日志；**不改变 C 端资产归属**

- 其中涉及“素材更新/版本采纳”的日志，只表示主持人在 B 端交付视角是否采用新版本，不等于对 C 端资产做修改

- **C 端变化可触发 B 端“已更新”提示与采纳操作记录；B 端任何操作不得反向影响 C 端内容**


### 9）页面底部说明（可选但建议）

- 提示文案：

- “日志仅记录当前主持人账号名下项目”

- “创建项目成功才扣配额；生成失败不扣配额”

- “会员开通/续费会产生配额增加记录，便于自查对账”
