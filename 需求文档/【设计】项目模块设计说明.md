# 项目模块设计说明

> 基于需求文档及模块讨论共识整理，定义项目模块的业务范围、功能、流程与表设计。

---

## 一、模块定位

**项目模块**以「婚礼项目」为核心，负责项目的创建、状态、成员绑定、生成物归属与分享入口，是 B 端主持人的主工作入口。

---

## 二、业务范围

### 2.1 项目生命周期管理

| 职责 | 说明 |
|------|------|
| 项目创建 | 主持人新建婚礼项目，填写新郎姓名、新娘姓名、婚礼日期；创建成功扣 1 次项目配额 |
| 项目状态 | 草稿 / 进行中 / 已完成 / 已归档 / 已禁用 等状态及流转 |
| 项目列表 | 主持人查看自己的项目列表，分页、排序 |
| 项目详情 | 查看单个项目完整信息（含成员、生成物状态） |
| 项目归档/禁用 | 项目结束后的归档或异常禁用（v0.1 可简化） |

### 2.2 项目成员管理（核心：用户绑定）

| 职责 | 说明 |
|------|------|
| 席位定义 | 项目创建时定义新郎、新娘两个席位（v0.1 固定） |
| **成员绑定** | 用户扫码并选择身份后，用 **user_id** 绑定到项目对应角色 |
| 绑定关系 | project_id + user_id + role（新郎/新娘） |
| 绑定状态 | 席位是否已占用、被谁占用、进度概览 |

**成员绑定流程**：

```
用户扫码进入
    │
    ▼
步骤1：判断用户是否存在（如按微信 openid 查询）
    ├── 不存在 → 创建用户（用户模块）
    └── 已存在 → 使用现有用户
    │
    ▼
步骤2：用户选择身份（新郎/新娘）
    │
    ▼
步骤3：在项目下绑定角色（使用 user_id）
    绑定：project_id + user_id + role
```

### 2.3 项目生成物管理

| 职责 | 说明 |
|------|------|
| **生成物与项目绑定** | 生成物创建时即绑定到项目，归属项目维度 |
| **项目维度的生成物列表** | 项目详情页展示「本项目的生成物」 |
| 状态概览 | 未生成 / 生成中 / 已生成 / 待更新 |

**边界**：项目模块负责归属与列表展示；交付物模块负责生成、编辑、删除。

### 2.4 分享

| 职责 | 说明 |
|------|------|
| 分享入口生成 | 为项目生成专属采访入口（二维码、链接） |
| 分享入口管理 | 复制链接、下载二维码、打开链接 |
| 入口与项目绑定 | 扫码/打开链接可解析出 project_id |

## 三、模块边界

| 不负责 | 归属模块 |
|--------|----------|
| 配额扣减逻辑 | 用户模块（项目模块触发） |
| 用户创建与存在性判断 | 用户模块 |
| 采访、对话、板块小结 | 会话管理 |
| 素材确认、素材快照 | 会话管理 |
| 生成任务发起、生成结果编辑 | 交付物模块 |
| 板块类型与顺序 | 板块管理 |

## 四、与其它模块的关系

| 调用方 | 调用场景 | 项目模块提供 |
|--------|----------|--------------|
| 用户模块 | 创建项目 | 项目模块触发配额扣减 |
| 用户模块 | 扫码进入 | 项目模块在绑定前需用户模块提供/创建 user_id |
| 会话管理 | C 端采访 | 项目上下文、参与者绑定（project_participant_id） |
| 交付物模块 | 生成交付物 | 项目归属、生成物绑定 project_id |
| B 端主持人 | 日常使用 | 项目列表、详情、分享、成员进度、生成物状态 |

## 五、核心业务流程

### 5.1 创建项目

1. 主持人填写新郎姓名、新娘姓名、婚礼日期  
2. 调用用户模块校验并扣减 1 次项目配额  
3. 创建项目记录，生成 share_token  
4. 定义新郎、新娘两个席位（占位，尚未绑定 user_id）

### 5.2 扫码进入 → 成员绑定

1. 用户扫码，携带 share_token 或 project_id 进入  
2. 用户模块：判断用户是否存在（如微信 openid），不存在则创建，得到 user_id  
3. 用户选择身份（新郎/新娘）  
4. 项目模块：创建 project_participant（project_id + user_id + role）  
5. 进入采访（会话管理基于该绑定创建会话）

### 5.3 项目详情

1. **素材库**：展示新郎、新娘各自的四板块完成与确认状态（数据来自会话管理）  
2. **生成区**：展示本项目下开场白、新郎誓言、新娘誓言的状态与操作入口

## 六、功能列表

### 6.1 B 端（主持人）

| 编号 | 功能 | 说明 |
|------|------|------|
| P-B01 | 项目列表 | 分页、按状态筛选、按创建时间排序 |
| P-B02 | 新建项目 | 新郎姓名、新娘姓名、婚礼日期；扣配额 |
| P-B03 | 项目详情 | 项目信息、成员状态、生成物列表 |
| P-B04 | 分享采访入口 | 二维码、链接；复制、下载、打开 |
| P-B05 | 进入项目详情 | 从列表点击进入 |

### 6.2 C 端（参与者）

| 编号 | 功能 | 说明 |
|------|------|------|
| P-C01 | 扫码进入 | 解析 share_token 获取 project_id |
| P-C02 | 身份选择 | 新郎/新娘二选一；授权勾选 |
| P-C03 | 成员绑定 | 选择身份后，创建 project_id + user_id + role 绑定 |
| P-C04 | 进入采访 | 绑定成功后跳转采访页（会话管理） |

### 6.3 与用户模块协作

| 编号 | 功能 | 说明 |
|------|------|------|
| P-U01 | 用户存在性判断 | 扫码进入时，根据微信 openid 等判断用户是否存在 |
| P-U02 | 用户创建 | 不存在时创建用户，返回 user_id |
| P-U03 | 配额扣减 | 创建项目时扣减主持人 1 次项目配额 |

## 七、业务表设计

### 7.1 表结构总览

```
project (项目主表)
    │
    ├── project_participant (项目参与者，project_id + user_id + role)
    │
    └── generated_content (生成物，归属项目，交付物模块维护)
```

### 7.2 project（项目主表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 主键 |
| project_no | varchar(32) | 项目编号，唯一 |
| title | varchar(100) | 项目标题（可自动生成） |
| groom_name | varchar(50) | 新郎姓名 |
| bride_name | varchar(50) | 新娘姓名 |
| wedding_date | date | 婚礼日期 |
| host_user_id | bigint | 主持人 user_id |
| status | varchar(20) | DRAFT/ACTIVE/COMPLETED/ARCHIVED/DISABLED |
| share_token | varchar(64) | 分享令牌，唯一，用于生成链接 |
| created_at | datetime | |
| updated_at | datetime | |
| deleted_at | datetime | 逻辑删除 |

### 7.3 project_participant（项目参与者）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 主键 |
| project_id | bigint | 项目 ID |
| user_id | bigint | 用户 ID（关联 user 表） |
| role_type | varchar(20) | GROOM/BRIDE |
| status | varchar(20) | INVITED/ENTERED/IN_PROGRESS/COMPLETED 等 |
| current_board_order | int | 当前进行到第几板块（1-4） |
| joined_at | datetime | 绑定时间 |
| last_active_at | datetime | 最后活跃时间 |
| created_at | datetime | |
| updated_at | datetime | |

**约束**：同一项目下，(project_id, role_type) 唯一；同一项目下，(project_id, user_id) 唯一（一人一项目一角色）。

### 7.4 generated_content（生成物，与交付物模块共用）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint | 主键 |
| project_id | bigint | 项目 ID（绑定项目） |
| participant_id | bigint | 参与者 ID（新郎誓言/新娘誓言关联；开场白可空） |
| content_type | varchar(20) | OPENING_SPEECH/GROOM_VOW/BRIDE_VOW |
| ... | | 其他字段由交付物模块定义 |

**说明**：generated_content 表可在交付物模块实现时创建，此处仅明确 project_id 为必填绑定字段。
