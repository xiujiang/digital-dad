# 前端数据字典与中文名对照

本文档汇总后端数据库、枚举、场景、提示词等 **code/枚举值** 与 **中文展示名** 的对应关系，供前端展示、多语言或下拉选项使用。

---

## 一、板块（board_meta / project_board）

表 `board_meta` 定义平台级板块类型；`project_board` 表示某项目下启用了哪些板块。  
前端常见用法：项目板块列表、采访/小结按板块筛选。

| code（唯一） | 中文名 | 说明 |
|--------------|--------|------|
| FAMILY_ORIGIN | 原生家庭 | 采访板块：原生家庭相关内容 |
| GROWTH | 成长轨迹 | 采访板块：成长经历相关内容 |
| LOVE_STORY | 爱情故事 | 采访板块：爱情故事相关内容 |
| FUTURE_PROMISE | 未来承诺 | 采访板块：未来承诺相关内容 |

- 接口返回中可能用 `boardMetaId` 或 `boardMeta.code`，展示时用上表 **中文名** 即可。
- 顺序：按 `display_order`（1=原生家庭，2=成长轨迹，3=爱情故事，4=未来承诺）。

## 二、场景（prompt_scene）

表 `prompt_scene`：提示词使用场景。按 **scope** 分为三类，调用「按场景取提示词」时使用 **code**。

### 2.1 交付物类（scope = DELIVERABLE）

| 场景 code | 中文名 | 说明 |
|-----------|--------|------|
| DELIVERABLE_OPENING_SPEECH | 婚礼开场白 | 生成婚礼开场白文案 |
| DELIVERABLE_GROOM_VOW | 新郎誓言 | 生成新郎誓言 |
| DELIVERABLE_BRIDE_VOW | 新娘誓言 | 生成新娘誓言 |

### 2.2 板块小结类（scope = BOARD_SUMMARY）

| 场景 code | 中文名 | 对应板块 |
|-----------|--------|----------|
| BOARD_SUMMARY_COMMON | 通用板块小结 | 兜底，无板块时使用 |
| BOARD_SUMMARY_FAMILY_ORIGIN | 原生家庭 · 板块小结 | FAMILY_ORIGIN |
| BOARD_SUMMARY_GROWTH | 成长轨迹 · 板块小结 | GROWTH |
| BOARD_SUMMARY_LOVE_STORY | 爱情故事 · 板块小结 | LOVE_STORY |
| BOARD_SUMMARY_FUTURE_PROMISE | 未来承诺 · 板块小结 | FUTURE_PROMISE |

### 2.3 采访类（scope = BOARD_INTERVIEW）

采访相关场景均属于 **BOARD_INTERVIEW**，包括通用欢迎语和按板块+角色的具体采访。

| 场景 code | 中文名 | 说明 |
|-----------|--------|------|
| BOARD_INTERVIEW_WELCOME | 板块采访欢迎语 | 创建会话时首条 AI 欢迎语，通用（不限定板块），变量 {{boardName}} 由业务替换 |
| BOARD_INTERVIEW_FAMILY_ORIGIN_GROOM | 采访-原生家庭-新郎 | |
| BOARD_INTERVIEW_FAMILY_ORIGIN_BRIDE | 采访-原生家庭-新娘 | |
| BOARD_INTERVIEW_GROWTH_GROOM | 采访-成长轨迹-新郎 | |
| BOARD_INTERVIEW_GROWTH_BRIDE | 采访-成长轨迹-新娘 | |
| BOARD_INTERVIEW_LOVE_STORY_GROOM | 采访-爱情故事-新郎 | |
| BOARD_INTERVIEW_LOVE_STORY_BRIDE | 采访-爱情故事-新娘 | |
| BOARD_INTERVIEW_FUTURE_PROMISE_GROOM | 采访-未来承诺-新郎 | |
| BOARD_INTERVIEW_FUTURE_PROMISE_BRIDE | 采访-未来承诺-新娘 | |

具体采访场景编码格式：`BOARD_INTERVIEW_{板块code}_{角色}`，角色见第四节。若存在 `BOARD_INTERVIEW_COMMON_GROOM` / `BRIDE`，则为「通用 · 新郎/新娘采访」兜底。

## 五、场景 scope 与提示词 content_type（可选）

### 5.1 场景适用范围（PromptSceneScope）

| 枚举值 | 含义 |
|--------|------|
| DELIVERABLE | 交付物生成 |
| BOARD_SUMMARY | 板块小结 |
| BOARD_INTERVIEW | 采访 |

### 5.2 提示词内容类型（PromptContentType）

| 枚举值 | 含义 |
|--------|------|
| SYSTEM_ROLE | 系统角色设定 |
| QUESTION | 提问 |
| FOLLOW_UP | 追问策略 |
| SUMMARY | 小结 |
| GENERATE | 生成 |
| TEXT | 通用文本 |
