# 仪表盘（P01 系统总览）数据来源对照表

> 本文档用于确认仪表盘各指标的数据来源，便于实现 `GET /api/admin/dashboard` 接口。

---

## 一、模块 A：关键指标卡（今日概览）

| 指标 | 需求口径 | 数据来源 | 表/实体 | 查询方式 | 备注 |
|------|----------|----------|---------|----------|------|
| **今日新增项目** | 今天创建且状态有效的项目数 | project | `project` | `COUNT` where `DATE(created_at)=今日` AND `deleted_at IS NULL` AND `status != DISABLED` | ✅ 有数据 |
| **今日采访会话数（活跃）** | 今天有有效交互的会话（至少一条录音或文本） | interview_session + conversation_message | `interview_session` | 今日 `last_active_at` 或今日有消息的 session 去重 | ✅ 有数据 |
| **今日生成次数** | 今天触发生成任务的次数（含成功/失败） | generated_content | `generated_content` | `COUNT` where `DATE(created_at)=今日` | ✅ 有数据 |
| **失败率** | 分子：今日失败生成数；分母：今日生成总数 | - | **无** | - | ⚠️ **暂无**：`generated_content` 无 FAILED 状态；AI 失败时抛异常不落库。首期建议返回 `0` 或 `null` |

## 七、实现建议

### 首期可实现的指标（有明确数据源）

1. 今日新增项目数
2. 今日采访会话数（活跃）
3. 今日生成次数
4. 失败率：返回 `0` 或 `null`，标注「暂无失败记录」
5. 语音识别分钟数（今日）
6. 模型调用消耗：返回 `0`，标注「待接入」
7. 存储对象数：用近似口径或返回 `0`
8. 最近失败记录：返回 `[]`
9. 最近项目
10. 总用户数
11. 待处理内容数（OUTDATED）

### 需要在 Repository 中新增的查询

- `ProjectRepository`：`countByCreatedAtBetween`、`findTop10ByDeletedAtIsNullOrderByCreatedAtDesc`
- `InterviewSessionRepository`：今日活跃会话数（按 `last_active_at` 或关联 `conversation_message`）
- `GeneratedContentRepository`：`countByCreatedAtBetween`、`countByStatus`
- `SpeechTranscriptionUsageRepository`：`sumDurationSecondsByCreatedAtBetween`
- `UserRepository`：`countByDeletedAtIsNull`（JPA 已有 `count()`）

---

确认后即可开始实现 `AdminDashboardController` 与 `AdminDashboardService`。
