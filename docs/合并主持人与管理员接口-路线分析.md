# 合并主持人与管理员接口 - 路线分析

本分支用于分析与实施「B 端主持人」与「超管」相关接口的合并，统一为一套 API + 角色鉴权。

---

## 一、目标

- 将 `/api/b/**`（主持人）与 `/api/admin/**`（超管）中**功能重叠**的接口合并为同一路径。
- 通过**角色**（HOST / SUPER_ADMIN）控制可见范围与可操作范围，前端一套资源模型。

---

## 二、合并清单与优先级

| 序号 | 模块 | 现状（主持人 / 管理员） | 合并后路径建议 | 鉴权规则 |
|------|------|------------------------|----------------|----------|
| 1 | 认证 | /api/auth/login、/me 与 /api/admin/auth/login、/me | /api/auth/login、/api/auth/me | 登录返回 role；me 共用，返回当前用户+角色 |
| 2 | 项目列表 | /api/b/projects（我的）与 /api/admin/projects（全部） | /api/projects | 列表：HOST 仅本人，SUPER_ADMIN 全部（可加 ?scope=all）；详情：HOST 仅本人项目，SUPER_ADMIN 任意 |
| 3 | 项目详情 | /api/b/projects/{id} 与 /api/admin/projects/{id} | /api/projects/{id} | 同上 |
| 4 | 板块元数据列表 | /api/b/board-meta/enabled 与 /api/admin/board-meta | /api/board-meta | 列表：HOST 仅启用，SUPER_ADMIN 全部；增删改仅 SUPER_ADMIN |
| 5 | 用户/主持人 | /api/b/users/me 与 /api/admin/hosts（CRUD+配额等） | /api/users/me、/api/users、/api/users/{id}… | me 共用；/users 及对某 id 的操作仅 SUPER_ADMIN |
| 6 | 项目下板块 | /api/b/projects/{id}/boards | /api/projects/{id}/boards | 保持子资源，鉴权：HOST 仅本人项目，SUPER_ADMIN 可按需开放 |
| 7 | 项目下交付物、分享 | /api/b/projects/{id}/deliverables、share | /api/projects/{id}/deliverables、share | 同上 |

**仅管理员、无主持人版本的接口**（路径可统一到 /api 下，不合并两套）：  
提示词（/api/prompt-templates、/api/prompt-scenes、/api/prompts/…）、主持人管理中的配额/流水等，保持仅 SUPER_ADMIN 可访问。

---

## 三、实施路线（建议顺序）

1. **认证合并**：统一 login/me，返回 role；前端根据 role 区分入口。
2. **Security 调整**：由「路径 /api/b、/api/admin」改为「路径 + 角色」：如 /api/projects 需登录，列表/详情内部按 principal 角色过滤或放行。
3. **项目接口合并**：提供统一 GET /api/projects、GET /api/projects/{id}，Service 层按角色决定查「本人」还是「全部」。
4. **板块元数据合并**：统一 GET /api/board-meta（及 CRUD），列表按角色或参数返回启用/全部。
5. **用户资源合并**：/api/users/me 共用；/api/users、/api/users/{id} 及子操作仅 SUPER_ADMIN。
6. **项目子资源**：将 /api/b/projects/{id}/* 迁移到 /api/projects/{id}/*，鉴权统一为「项目归属或超管」。
7. **废弃与兼容**：标记原 /api/b、/api/admin 中已合并接口为 deprecated 或重定向，必要时保留一段时间兼容。

## 五、已实施变更摘要

- **认证**：已合并为 /api/auth（login 用 admin 参数区分，me 共用）。
- **项目**：统一为 ProjectController @ /api/projects（列表/详情按角色；子资源 /api/projects/{id}/share、deliverables）。
- **项目下板块**：ProjectBoardController 路径改为 /api/projects/{projectId}/boards。
- **板块元数据**：统一为 BoardMetaController @ /api/board-meta（列表按角色，CRUD 仅 SUPER_ADMIN）。
- **用户/主持人**：统一为 UserController @ /api/users（me 共用；列表、详情、状态、会员、配额等仅 SUPER_ADMIN）。
- **交付物**：ProjectController 提供 /api/projects/{id}/deliverables/*；DeliverableController @ /api/deliverables/{id} 提供 get/put/delete。
- **已删除**：AdminAuthController、AdminProjectController、AdminBoardMetaController、AdminHostController、HostUserController；原 /api/b 对应能力已迁至上述统一路径。
